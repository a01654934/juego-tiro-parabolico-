Este proyecto es una modificación del juego Cannon basado en la librería freegames.
El objetivo del juego es disparar proyectiles para golpear los blancos en movimiento.
Se realizaron mejoras para:
Incrementar la velocidad del proyectil y los objetivos
Evitar que el juego termine
Reposicionar objetivos cuando salen de la pantalla

feat(cannon): increase projectile and target speed for faster gameplay
feat(cannon): make game endless by respawning targets when exiting screen
